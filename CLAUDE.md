# Music-Wise — Claude Project Context

## What this app is
A music theory learning and reference tool targeting guitar and piano players. Users select a key and scale to visualize notes on a 24-note scrollable strip, a guitar fretboard (22 frets × 6 strings), and a piano keyboard (2 octaves). A chords section shows diatonic chords for the selected key/scale.

## Tech stack
- **Stencil 4** — web components compiled to vanilla custom elements
- **Ionic Core 8** — UI components (ion-header, ion-card, ion-item, etc.)
- **TypeScript** — strict types throughout
- PWA output to `www/`; dev server: `npm start`; build: `npm run build`

## Architecture
```
src/
  services/
    theory.ts       ← Core music theory engine (the "brain")
    app-state.ts    ← Global state singleton (App); persists to localStorage
    switchboard.ts  ← Custom pub/sub event bus between components
  components/       ← 18 Stencil web components
  interfaces/
    application.ts  ← Note, Chord, ChordGroup, Scale, ScaleGroup interfaces
```

### State flow
1. `key-scale-selector` emits `keyChanged` / `scaleChanged` DOM events
2. `app-root` listens, calls `TheoryService.generateKeyNotes()` and `generateKeyChordGroups()`
3. Updated `keyNotes` / `chordGroups` are broadcast via `switchboard`
4. All display components (`notes-section`, `piano-section`, `guitar-section`, `chords-section`) re-render

### Note coloring convention
- **Secondary** = root / tonic
- **Tertiary** = diatonic scale tones
- **Light/Medium** = chromatic (non-diatonic) notes

## Key design decisions
- `generateKeyNotes()` always produces 24 notes (two diatonic octaves + chromatic fill), covering all positions on the guitar fretboard and piano
- `generateKeyChordGroups()` always builds chords against a **major scale** reference for each root note — chord intervals are absolute (1, ♭3, 5 for minor regardless of key)
- Guitar tuning is stored in `App.state.guitarTuning` (default: E A D G B E) and can be changed

## Development notes
- `components.d.ts` is auto-generated by Stencil — do not hand-edit
- `theory.ts` is a singleton (`TheoryController` class, exported as `TheoryService`)
- All `TheoryService` methods are `async` even though they return in-memory data
- The `intervalPattern` string format uses `|`-delimited tokens: `1`, `2`…`7`, `♭2`…`♭7`, `♯4`, or `-` (skip/chromatic)
